# P1-DEPLOY-001-服务502错误

## 问题描述
图片压缩工具站服务无法访问，返回 502 Bad Gateway 错误

## 影响范围
- 文件：整个站点服务
- 模块：部署/运维
- 影响：阻塞所有测试用例执行

## 复现步骤
1. 访问 http://192.168.3.9:8088/
2. 执行 `curl -I http://192.168.3.9:8088/`
3. 返回 `HTTP/1.1 502 Bad Gateway`

## 修复方案
1. SSH到Mac Mini检查Docker容器状态
2. 检查nginx配置和端口占用
3. 重启docker-compose服务
4. 验证WASM文件是否存在
